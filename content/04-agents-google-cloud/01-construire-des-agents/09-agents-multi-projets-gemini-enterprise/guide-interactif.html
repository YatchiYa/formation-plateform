For now, Terraform runs from a person's machine or Cloud Shell, not from a CI pipeline. The state file (terraform.tfstate.d/scenario-…/terraform.tfstate, one workspace per scenario) lives in the folder where you run it, and Terraform acts with your identity. One person at a time per folder, and never lose or commit the state.

Pour l'instant, Terraform s'exécute depuis le poste d'une personne ou Cloud Shell, pas depuis une chaîne CI. Le fichier d'état (terraform.tfstate.d/scenario-…/terraform.tfstate, un espace de travail par scénario) vit dans le dossier où vous le lancez, et Terraform agit avec votre identité. Une personne à la fois par dossier, et ne jamais perdre ni committer l'état.
