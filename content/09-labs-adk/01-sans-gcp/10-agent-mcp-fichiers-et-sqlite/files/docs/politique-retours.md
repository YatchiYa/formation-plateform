# Politique de retours (Boutique Atelier Vélo, fictive)

- Le client dispose de **30 jours** après la livraison pour retourner un article.
- Les articles doivent être non utilisés et dans leur emballage d'origine.
- Les commandes au statut `livree` peuvent être remboursées ; les commandes `en_preparation` sont simplement annulées.
- Les pièces détachées sur mesure (catégorie `sur-mesure`) ne sont **ni reprises ni échangées**.
- Le remboursement est effectué sous 14 jours sur le moyen de paiement d'origine.
